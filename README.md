# Meal Prep Agent

料理備餐互動 LLM Agent 展示作品，協助使用者依飲食目標安排可調整的三天餐單，以自煮為主並支援固定外食。

## 目前狀態

已確認 MVP 產品方向、只用免費模型額度，並允許使用 Cloudflare。[產品規格](product-spec.md) 已整理互動流程、資料契約、保存方式與驗收案例；[營養政策 v1](nutrition-policy.md) 定義 DRI 2023 起始估算、配餐容許差及數值邊界。Cloudflare 候選架構仍須整合驗證。目前尚無可執行應用、套件清單、測試或部署，規劃內容不代表功能已完成。

## MVP 範圍

- 「我已有目標」與「幫我設定目標」兩種入口，確認後共用餐單流程。
- 自煮餐點與固定早餐／外食、每日預計營養與資料完整性。
- 局部換菜、調份量、鎖定、變更預覽及復原；營養與清單同步重算。
- 合併備餐與購物清單，條件無法同時滿足時提供協商選項。

## 開發方向

- Agent 框架採 Google ADK TypeScript，互動協定採 AG-UI；尚未安裝依賴或完成整合。
- 優先評估 React＋Vite、Workers Static Assets／Worker API 與 Workers AI；模型 adapter、workerd 相容性與免費額度行為須先驗證。額度用完暫停新的 AI 操作，保留既有計畫，不自動啟用付費服務。
- 保存採免登入的本機 IndexedDB，保留已採用計畫與前一版；30 天未修改後到期，下一次讀取清除。身體表單與聊天不持久化，模型對話的資料流另行說明。
- 這是可獨立開發與部署的產品；不依賴其他作品的執行環境。
- 先完成免費模型／Cloudflare 的最小可行性驗證，再依規格與營養政策建立可執行骨架及受影響測試。
- 展示先使用明確標示的合成資料，不將估算營養或成本當成已驗證事實。

開發前請讀 [AGENTS.md](AGENTS.md)。目前沒有可執行的安裝、啟動或測試指令。
